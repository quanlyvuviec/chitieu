Cài đặt

Sao lưu sẽ tải về 1 file .json chứa toàn bộ dữ liệu hiện tại. Khôi phục sẽ ghi đè toàn bộ dữ liệu đang có bằng nội dung file bạn chọn.

Kết nối để dữ liệu tự động lưu trên đám mây và xem được ở bất kỳ đâu, nhiều người dùng theo thời gian thực. Tạo project miễn phí tại console.firebase.google.com → bật Realtime Database → vào Project settings ⚙️ → General, điền các thông tin tương ứng bên dưới.

⚠ Bắt buộc để tránh lỗi "permission_denied":
1️⃣ Vào Authentication → Sign-in method → bật "Anonymous" (Ẩn danh).
2️⃣ Vào Realtime Database → Rules, dán đúng nội dung sau rồi bấm Publish:

{ "rules": { ".read": "auth != null", ".write": "auth != null" } }

Ứng dụng sẽ tự động đăng nhập ẩn danh (không cần tài khoản/mật khẩu Firebase riêng) mỗi khi kết nối — Rules trên đảm bảo chỉ ứng dụng đã xác thực mới đọc/ghi được, chặn người lạ truy cập trực tiếp vào đường link database.

* Bắt buộc — 3 ô còn lại có thể để trống nếu chỉ dùng Realtime Database.

Sau khi kết nối, dữ liệu sẽ tự động lưu thẳng lên Firebase mỗi khi bạn thêm/sửa/xóa — không còn lưu trong bộ nhớ trình duyệt (localStorage) nữa. Cần có kết nối Internet để đồng bộ; nếu ngắt kết nối, hệ thống quay lại lưu cục bộ như bình thường.

📱 Dùng trên nhiều thiết bị (VD: điện thoại): mỗi trình duyệt/thiết bị lưu cấu hình riêng nên cần nhập 1 lần cho từng máy. Để nhanh gọn, hãy sao chép cấu hình từ máy đã kết nối rồi dán vào thiết bị mới thay vì gõ lại từng ô.
